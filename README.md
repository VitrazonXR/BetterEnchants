# BetterEnchants 🪄
A simple and useful mod for Minecraft Java Edition which lets you enchant any item with any enchantment with a value of 0-255.
 
With this mod, you can enchant any item with any enchantment with a value of 0-255.

You can enchant stuff much past their original Vanilla value and you can remove enchantments (using 0)

When using this mod, it automatically enchants whatever is currently selected in your hotbar.

You can download the mod here ---> https://github.com/VitrazonXR/BetterEnchants/releases/tag/Version_One

# How to Use 🏫
The style used in game is "/enchant <enchantment> <level>", so some examples could be,
"/enchant aqua_affinity 255", 
"/enchant unbreaking 1", or 
"/enchant smite 5"

This mod is very user-friendly no matter if you're a noob or pro at coding or using commands in Minecraft.

# Compatiblilty 📋
This mod is very versatile as it it can currently be used in any Minecraft Java version between 1.13 and 1.21.x and can also be used in 26.1.x

This mod is fully supported in Paper, Purpur, Spigot, CraftBukkit, Pufferfish, Airplane, and other Paper forks. It is partially supported by Folia, however it may not work properly in it. Unfortunately, this mod does not support Vanilla, Fabric, Forge, Cardboard, Bedrock, or PocketMine, although I would advise to stay tuned as versions of this mod will likely be out on those platforms soon.

It is compatible with anything using some form of Paper API and it works on any Bukkit-based server.

# Permissions 👑
These commands only work for admins/operators of the server, which is useful so others don't abuse any of these powers.

anyenchant.use Allows the use of the command and it's default is OP.

# How it Works 📚
AnyEnchant uses the Bukkit API’s addUnsafeEnchantment method to bypass vanilla restrictions and apply enchantments directly to the item in the player’s main hand.
It also supports both namespaced keys (sharpness) and legacy names (SHARPNESS) for maximum compatibility.

# Uses ⚔️
This can be used to create custom OP items, run admin events, test enchantment behavior, make funny cursed items, give players unique rewards, build custom minigames, or just have fun being overpowered!
